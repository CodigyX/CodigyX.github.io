# Retrato digital de Erick

Generado con la herramienta integrada de imágenes, mediante edición del retrato anterior. La variante pixel art fue seleccionada porque la primera variante de render 3D conservaba un rostro demasiado fotográfico. No es un modelo 3D interactivo.

Referencia: erick-angel-avatar.webp. Resultado: erick-angel-avatar-pixel.webp, WebP sin pérdida. El original permanece conservado.

## Prompt final

Use case: style-transfer. Edit target: provided Erick angel warrior portrait. Transform the ENTIRE portrait into authentic high-quality hand-pixeled 32-bit era JRPG character portrait pixel art. This is NOT a photo with pixel filter: completely redraw face, hair, beard, skin, armor and feathers using visibly large discrete square pixel clusters and a limited 32-color palette. Logical canvas about 240x360 scaled up nearest neighbor. No smooth gradients, no photographic face, no skin pores, no antialiasing. Strong requirement FACE MUST BE PIXEL ART, recognizable same short black swept hair, dark brows, brown eyes, small chin beard, face shape and calm masculine expression. Warm tan skin with just 4 flat stepped shades plus violet rim pixels. Same silver and gold armor, purple gems, white wings, staff, halo, same pose and thigh-up framing. Polished game character selection illustration. Dark solid midnight violet background compatible with portfolio. No text, UI or border. User explicitly prefers pixel to a realistic pasted face. Make the pixel grid visually evident.
